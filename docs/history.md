# History and naming

`tclaude` began as Claude Code and tmux utilities and grew into multi-harness
coordination. [The origin story](stories/origin-story.md) is a historical account
of that earlier implementation, not a guide to current commands.

The current backend separates stable agents, logical conversations, concrete
executions and durable work outcomes. Historical `TCLAUDE_` names identify the
product, not a Claude-only boundary. The old source schema is retained as a
versioned offline migration fixture, without the old daemon or runtime handles.
