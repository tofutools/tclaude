# Shard map for the filtered-proxy smokes.
#
# Each line: <shard-name> <flows|harnesses> <item>...
#
# A shard is a subset of the flows that one CI job runs, plus the harnesses that
# job has to install. The split exists because the two halves are independent:
# flows 10 and 20 exercise the session-layer proxy with Claude Code and Codex,
# flows 30 and 40 exercise the agentd-owned OpenCode relay — disjoint subnets,
# disjoint harnesses, disjoint Go packages. Running them as two jobs halves the
# wall-clock and lets each job install only the harnesses it actually launches.
#
# The split is at the JOB level, not inside one run. `fixture::hosts_add` and
# `fixture::hosts_restore` (scripts/lib/smoke/fixture.sh) mutate /etc/hosts
# through a single shared backup file, so two flows running concurrently in one
# process would clobber each other's resolver state. Do not try to parallelise
# within a shard.
#
# THE GUARD: run.sh refuses to run unless the union of every shard's flow list
# covers every flow the manifest names, and unless the union of every shard's
# harness list covers every harness lib/harnesses.sh knows how to install. A
# flow that belongs to no shard would silently stop running while both CI jobs
# stayed green — the vacuous shape the evidence discipline exists to refuse —
# and a harness that belongs to no shard would be installed by nobody while the
# flow needing it failed with "not found". Both checks are self-tested in
# scripts/lib/smoke/selftest.sh, which every run executes before trusting
# anything, so the guard cannot rot unnoticed either.
#
# Adding a flow therefore costs two edits, both reviewable: a manifest.txt line
# saying what evidence it must produce, and a shards.txt entry saying which job
# runs it. Forgetting the second one fails the run rather than passing quietly.

# Session-layer proxy floor, policy engine and pinned-harness egress.
session flows      10-floor-policy 20-harness-egress
session harnesses  claude codex

# The agentd-owned OpenCode relay: carriage answer and real floor cooperation.
agentd  flows      30-opencode-carriage 40-opencode-floor
